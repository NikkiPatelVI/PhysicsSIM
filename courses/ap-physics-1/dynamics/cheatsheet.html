Newton's Three Laws

Newton's 1st Law — Inertia
ΣF = 0 ↔ a = 0
An object at rest stays at rest; an object in motion stays in motion at constant velocity — unless acted on by a net external force.
ΣF — net (vector sum of all) forces (N) a — acceleration (m/s²)
Where does this come from?

Galileo's insight, formalized by Newton: on a frictionless surface, a moving object keeps moving forever. "Inertia" is mass resisting velocity changes. The 1st Law is a special case of the 2nd: if ΣF = 0 then a = ΣF/m = 0. It also defines what an "inertial reference frame" is — one where the 1st Law holds.

Newton's 2nd Law
ΣF = ma
The master dynamics equation. Net force equals mass times acceleration. Apply separately in x and y directions.
ΣF — net force (N) m — mass (kg) a — acceleration (m/s²)
Where does this come from?

Empirical: doubling net force doubles acceleration; doubling mass halves it. This relation defines the unit of force — 1 N gives 1 kg an acceleration of 1 m/s². More precisely, ΣF = dp/dt (rate of change of momentum), which reduces to ma when mass is constant.

Newton's 3rd Law
F₁₂ = −F₂₁
Every force has an equal and opposite reaction force acting on a different object. The two forces are always equal in magnitude and opposite in direction.
F₁₂ — force object 1 exerts on object 2 (N) F₂₁ — force object 2 exerts on object 1 (N)
Where does this come from?

Follows from conservation of momentum. When two objects interact in an isolated system, any momentum gained by one must be lost by the other: Δp₁ = −Δp₂. Dividing by Δt gives F₁₂ = −F₂₁. Key: the forces act on different objects, so they never cancel each other in a single FBD.

Common Forces

Weight
W = mg
Gravitational force on an object, always directed downward toward Earth's center. Weight is a force; mass is not.
W — weight (N) m — mass (kg) g = 9.8 m/s²
Where does this come from?

Apply ΣF = ma to a freely falling object. The only force is gravity, and experiment shows a = g = 9.8 m/s² downward for every object. So F_gravity = mg. Near Earth's surface this is constant — it changes slightly with altitude (full formula: F = GMm/r², where M is Earth's mass).

Normal Force
N ⊥ surface
Contact force perpendicular to the surface. N = mg only on a horizontal surface with no vertical applied forces — always derive it from ΣF_y = 0.
N — normal force (N) Direction: perpendicular (outward) from surface
Where does this come from?

Electromagnetic repulsion between the atoms of the object and surface prevents interpenetration. Macroscopically, N is whatever value is needed so the object doesn't accelerate through the surface: ΣF_⊥ = 0 → N = (sum of all perpendicular force components). Never assume N = mg on inclines or when vertical forces are applied.

Static Friction
f_s ≤ μ_s N
Prevents motion. Self-adjusts up to a maximum of μ_s N. Use f_s = μ_s N only at the instant of impending motion.
f_s — static friction force (N) μ_s — coefficient of static friction (unitless) N — normal force (N)
Where does this come from?

Empirical: increase applied force on a stationary block. Friction grows to match it (ΣF = 0) until the block breaks free at f_s,max. The ratio f_s,max/N is remarkably consistent for a given surface pair — define this as μ_s. Below max, use ΣF = 0 to find the actual friction value; it's an inequality, not an equation.

Kinetic Friction
f_k = μ_k N
Opposes sliding motion. Constant once the object is moving. Always μ_k < μ_s — it's easier to keep something moving than to start it.
f_k — kinetic friction force (N) μ_k — coefficient of kinetic friction (unitless) N — normal force (N)
Where does this come from?

Empirical: once sliding, the friction force is approximately constant regardless of speed and independent of contact area (surprising!). Why μ_k < μ_s? Static contact involves stronger adhesion between asperities; during sliding, microscopic bonds break and reform rapidly, giving lower average force. The model breaks down at very high speeds but is accurate for AP scenarios.

Hooke's Law (Spring)
F_s = kx
The spring force is proportional to the stretch or compression from equilibrium. The spring always pulls back toward equilibrium (restoring force).
F_s — spring force (N) k — spring constant (N/m) x — displacement from equilibrium (m)
Where does this come from?

Hooke's empirical law (1678): "as the extension, so the force." Within the elastic limit, deformation is proportional to applied force. The spring constant k reflects the material stiffness — stiffer material = larger k. Beyond the elastic limit (too much stretch), the spring deforms permanently and Hooke's Law breaks down.

Tension
T along string (pulls)
Tension acts along a string or rope, always pulling (never pushing). For a massless string, tension is the same at every point along it.
T — tension (N) Massless string: T is uniform throughout Direction: along string, toward the string
Where does this come from?

For a massless string, apply ΣF = ma to any segment: m = 0 so ΣF = 0, meaning tensions at both ends must be equal. This propagates throughout → T is uniform. Over a frictionless, massless pulley, T is also preserved because the pulley only changes direction, not magnitude. If the string has mass, T varies and you must apply Newton's 2nd Law to each segment.

Inclined Planes

Weight Components
F_∥ = mg sinθ  ·  F_⊥ = mg cosθ
Decompose weight along (∥) and perpendicular (⊥) to the slope. The perpendicular component equals the normal force on a frictionless incline.
F_∥ — component down the slope (N) F_⊥ — component into the surface (N) θ — angle of incline from horizontal
Where does this come from?

Tilt the coordinate axes so x is along the slope. The weight vector mg points straight down. The angle between the slope-normal and the vertical equals θ (alternate interior angles from the geometry). So the component along the slope = mg sinθ (opposite side) and the component into the slope = mg cosθ (adjacent side). Draw the right triangle once and you'll never mix them up.

Frictionless Incline
a = g sinθ  ·  N = mg cosθ
On a frictionless slope, only the parallel component of gravity drives acceleration. Mass cancels — every object accelerates at g sinθ regardless of mass.
a — acceleration down slope (m/s²) N — normal force (N) θ — slope angle
Where does this come from?

Along slope: only mg sinθ acts → mg sinθ = ma → divide by m → a = g sinθ. Perpendicular: ΣF = 0 → N = mg cosθ. Mass cancels because both the driving force (mg sinθ) and inertia (ma) scale with m. At θ = 0° (flat): a = 0. At θ = 90° (vertical): a = g (free fall). Makes sense!

Incline with Friction
a = g(sinθ − μ_k cosθ)
Friction acts up the slope opposing motion. Net acceleration still independent of mass. Object slides if tanθ > μ_s.
a — acceleration down slope (m/s²) μ_k — kinetic friction coefficient θ — slope angle
Where does this come from?

Along slope: mg sinθ − f_k = ma. f_k = μ_k·N = μ_k·mg cosθ. Substitute: mg sinθ − μ_k mg cosθ = ma. Divide by m: a = g(sinθ − μ_k cosθ). Sliding condition: the object begins sliding when mg sinθ > f_s,max = μ_s·mg cosθ → tanθ > μ_s. Mass cancels again — pure geometry and μ determine the threshold.

Multi-Body Systems

Atwood Machine
a = (m₂−m₁)g / (m₁+m₂)
Two masses over a frictionless pulley. Net force is the weight difference; total inertia is the sum. Heavier side accelerates downward.
m₁ — lighter mass (kg) m₂ — heavier mass (kg) a — acceleration of system (m/s²)
Where does this come from?

Write ΣF = ma for each mass with the same tension T and same acceleration magnitude a. m₂ (down): m₂g − T = m₂a. m₁ (up): T − m₁g = m₁a. Add the two equations (T cancels): (m₂−m₁)g = (m₁+m₂)a → divide: a = (m₂−m₁)g/(m₁+m₂). Shortcut: treat the whole system — net force = (m₂−m₁)g, total mass = (m₁+m₂).

Atwood Tension
T = 2m₁m₂g / (m₁+m₂)
Tension is between the two weight values (m₁g < T < m₂g). Verify: apply ΣF = ma to each mass separately using this T.
T — string tension (N) m₁, m₂ — the two masses (kg)
Where does this come from?

Substitute a back into m₁'s equation: T = m₁(g + a) = m₁g[1 + (m₂−m₁)/(m₁+m₂)] = m₁g · 2m₂/(m₁+m₂) = 2m₁m₂g/(m₁+m₂). Check limits: if m₁ = m₂ = m, then T = mg (static). If m₁ → 0, then T → 0 (free fall). These make physical sense.

Block on Table + Hanging Mass
a = m_h g / (m_t + m_h)
The hanging mass drives the system; the table mass provides inertia. For tension: T = m_t · a (from the table block's equation).
m_h — hanging mass (kg) m_t — table mass (kg) T — string tension = m_t · a (N)
Where does this come from?

Hanging mass (vertical): m_h·g − T = m_h·a. Table mass (horizontal): T = m_t·a. Add: m_h·g = (m_t + m_h)·a → a = m_h·g/(m_t+m_h). Same structure as Atwood — the "net driving force" is m_h·g (no counter-mass on other side), total inertia is (m_t+m_h). Adding friction to the table: subtract μ_k·m_t·g from the numerator.

Key Values & Units

Constants
g = 9.8 m/s² (gravitational acceleration)
μ_s > μ_k always (static > kinetic)
Typical μ_k (rubber on concrete) ≈ 0.7
SI Units
Force: N = kg·m/s²
Mass: kg
Acceleration: m/s²
Spring constant k: N/m
FBD Checklist
1. Draw the object as a dot
2. Weight: always downward
3. Normal: ⊥ to surface, outward
4. Friction: opposes motion or tendency
5. Tension: along string, toward string
6. Applied forces: direction given
