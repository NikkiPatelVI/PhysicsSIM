Core Definitions

Displacement
Δx = x_f − x_i
Change in position — a vector. Direction matters. Not the same as distance traveled.
Δx — displacement (m) x_f — final position (m) x_i — initial position (m)
Where does this come from?

Straight subtraction of position coordinates. The sign gives direction: positive means rightward (or upward), negative means leftward (or downward). Distance is |Δx|, which discards direction.

Average Velocity
v_avg = Δx / Δt
Displacement divided by time — a vector. Positive or negative depending on direction.
v_avg — average velocity (m/s) Δx — displacement (m) Δt — time interval (s)
Where does this come from?

Definition of "rate of change." It's the slope of a position-vs-time graph over an interval. Instantaneous velocity is the limit as Δt → 0, which gives the slope of the tangent line.

Average Acceleration
a_avg = Δv / Δt
Rate of change of velocity — a vector. An object can accelerate while slowing down.
a_avg — average acceleration (m/s²) Δv — change in velocity (m/s) Δt — time interval (s)
Where does this come from?

Same structure as velocity: "rate of change of velocity." It's the slope of a velocity-vs-time graph. An object decelerating has acceleration pointing opposite to its velocity — both are vectors.

The Four Kinematic Equations

Velocity — no Δx
v = v₀ + at
Use when displacement is not needed. Missing variable: Δx.
v — final velocity (m/s) v₀ — initial velocity (m/s) a — acceleration (m/s²) t — time (s)
Where does this come from?

Rearrange the definition of acceleration: a = (v − v₀)/t. Multiply both sides by t: at = v − v₀. Add v₀ to both sides → v = v₀ + at. That's it — one algebraic step from the definition.

Displacement — no v
Δx = v₀t + ½at²
Use when final velocity is unknown. Missing variable: v.
Δx — displacement (m) v₀ — initial velocity (m/s) a — acceleration (m/s²) t — time (s)
Where does this come from?

Area under the v-t graph. Velocity increases linearly from v₀ to v₀+at. That shape is a rectangle (base t, height v₀) plus a triangle (base t, height at). Area = v₀t + ½·t·at = v₀t + ½at².

Velocity² — no t
v² = v₀² + 2aΔx
Use when time is not given or needed. Missing variable: t.
v — final velocity (m/s) v₀ — initial velocity (m/s) a — acceleration (m/s²) Δx — displacement (m)
Where does this come from?

Eliminate t between the first two equations. From eq 1: t = (v−v₀)/a. Substitute into eq 2: Δx = v₀(v−v₀)/a + ½a·(v−v₀)²/a². Multiply through by 2a and simplify: 2aΔx = v² − v₀².

Displacement — no a
Δx = ½(v₀ + v)t
Averages initial and final velocity. Use when acceleration is unknown. Missing variable: a.
Δx — displacement (m) v₀ — initial velocity (m/s) v — final velocity (m/s) t — time (s)
Where does this come from?

For constant acceleration, the v-t graph is a straight line, so average velocity = midpoint = (v₀+v)/2. Then Δx = v_avg × t = ½(v₀+v)t. This only works when acceleration is constant.

Free Fall

Free-Fall Acceleration
a = −g = −9.8 m/s²
Acceleration is always downward. Apply kinematic equations with a = −9.8 m/s² when up is positive.
g = 9.8 m/s² (gravitational acceleration) Sign depends on chosen positive direction
Where does this come from?

Near Earth's surface, the gravitational field is approximately uniform: every kilogram of mass experiences a downward force of 9.8 N. From F = ma: a = F/m = 9.8 N/kg = 9.8 m/s². Air resistance is neglected in free fall.

Max Height (thrown upward)
h = v₀² / (2g)
At maximum height v = 0. Derived from v² = v₀² − 2gh setting v = 0.
h — max height above launch (m) v₀ — initial upward speed (m/s) g = 9.8 m/s²
Where does this come from?

At maximum height the object stops momentarily: v = 0. Plug into v² = v₀² − 2gh: 0 = v₀² − 2gh → h = v₀²/(2g). Direct algebraic substitution — no new physics needed.

Time to Max Height
t_up = v₀ / g
Time up equals time down for symmetric trajectories. Total air time = 2v₀/g.
t_up — time to reach max height (s) v₀ — initial upward speed (m/s) g = 9.8 m/s²
Where does this come from?

At max height v = 0. From v = v₀ − gt: set v = 0 → 0 = v₀ − g·t_up → t_up = v₀/g. Because the acceleration is symmetric (constant −g), the time back down equals t_up — total air time = 2v₀/g.

Projectile Motion

Launch Components
v_x = v₀cosθ  ·  v_y₀ = v₀sinθ
Decompose launch velocity into independent horizontal and vertical components at the start.
v₀ — launch speed (m/s) θ — launch angle above horizontal v_x — horizontal component (constant)
Where does this come from?

Vector decomposition using trigonometry. A vector of magnitude v₀ at angle θ has a horizontal projection v₀cosθ (adjacent side) and a vertical projection v₀sinθ (opposite side). These are perpendicular and completely independent of each other.

Horizontal Motion
x = v_x · t  (a_x = 0)
No horizontal force → no horizontal acceleration. Horizontal velocity stays constant throughout the flight.
x — horizontal displacement (m) v_x = v₀cosθ (m/s, constant) t — time (s)
Where does this come from?

Newton's 1st Law: no horizontal force (ignoring air) → no horizontal acceleration. Apply Δx = v_x·t + ½a_x t² with a_x = 0 → x = v_x·t. Horizontal motion is just uniform motion.

Vertical Motion
v_y = v_y₀ − gt
Vertical component is pure free fall. v_y = 0 at the peak; apply all four kinematic equations vertically.
v_y — vertical velocity (m/s) v_y₀ = v₀sinθ (initial vertical speed) g = 9.8 m/s²
Where does this come from?

The only vertical force is gravity (−mg). From Newton's 2nd Law: a_y = −g = −9.8 m/s². Apply the first kinematic equation vertically: v_y = v_y₀ + a_y·t = v_y₀ − gt. The horizontal and vertical components never affect each other.

Range (level ground)
R = v₀²sin(2θ) / g
Maximum range at θ = 45°. Complementary angles (e.g. 30° and 60°) give the same range.
R — horizontal range (m) v₀ — launch speed (m/s) θ — launch angle
Where does this come from?

Total air time T = 2v₀sinθ/g (double the time-to-peak). Range = v_x · T = v₀cosθ · 2v₀sinθ/g = v₀²·2sinθcosθ / g. Using the double-angle identity 2sinθcosθ = sin(2θ) gives R = v₀²sin(2θ)/g. Maximum when sin(2θ) = 1 → θ = 45°.

Final Speed (any point)
v = √(v_x² + v_y²)
Combine components with the Pythagorean theorem. Direction: θ = arctan(v_y / v_x) below horizontal.
v — speed at any point (m/s) v_x — horizontal component (m/s) v_y — vertical component at that instant (m/s)
Where does this come from?

The two velocity components are perpendicular vectors. The magnitude of the resultant uses the Pythagorean theorem: |v| = √(v_x² + v_y²). The angle below horizontal is arctan(|v_y|/v_x). This works at any point — bottom of arc, mid-flight, anywhere.

Key Values & Units

Constants
g = 9.8 m/s² (use 10 for quick estimates)
Free fall: a = −9.8 m/s² (up positive)
SI Units
Position / displacement: m
Velocity / speed: m/s
Acceleration: m/s²
Time: s
Scalars vs. Vectors
Vectors (have direction): displacement, velocity, acceleration
Scalars (magnitude only): distance, speed, time
