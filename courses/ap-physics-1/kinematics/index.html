Core Definitions

Displacement
Δx = x_f − x_i
Change in position — a vector. Direction matters. Not the same as distance traveled.
Δx — displacement (m) x_f — final position (m) x_i — initial position (m)
Average Velocity
v_avg = Δx / Δt
Displacement divided by time — a vector. Positive or negative depending on direction.
v_avg — average velocity (m/s) Δx — displacement (m) Δt — time interval (s)
Average Acceleration
a_avg = Δv / Δt
Rate of change of velocity — a vector. An object can accelerate while slowing down.
a_avg — average acceleration (m/s²) Δv — change in velocity (m/s) Δt — time interval (s)

The Four Kinematic Equations

Velocity — no displacement
v = v₀ + at
Use when displacement is not needed. Missing variable: Δx.
v — final velocity (m/s) v₀ — initial velocity (m/s) a — acceleration (m/s²) t — time (s)
Displacement — no final velocity
Δx = v₀t + ½at²
Use when final velocity is unknown. Missing variable: v.
Δx — displacement (m) v₀ — initial velocity (m/s) a — acceleration (m/s²) t — time (s)
Velocity squared — no time
v² = v₀² + 2aΔx
Use when time is not given or needed. Missing variable: t.
v — final velocity (m/s) v₀ — initial velocity (m/s) a — acceleration (m/s²) Δx — displacement (m)
Displacement — no acceleration
Δx = ½(v₀ + v)t
Use when acceleration is unknown. Averages initial and final velocity. Missing variable: a.
Δx — displacement (m) v₀ — initial velocity (m/s) v — final velocity (m/s) t — time (s)

Free Fall

Free-Fall Acceleration
a = −g = −9.8 m/s²
Acceleration is always downward. Apply the kinematic equations with a = −9.8 m/s² (if up is positive).
g — gravitational acceleration = 9.8 m/s² Sign depends on chosen positive direction
Max Height (thrown upward)
h = v₀² / (2g)
At maximum height v = 0. Derived from v² = v₀² − 2gh with v = 0.
h — max height above launch (m) v₀ — initial upward speed (m/s) g — 9.8 m/s²
Time to Max Height
t_up = v₀ / g
Time up equals time down for symmetric trajectories. Total air time = 2v₀/g.
t_up — time to reach max height (s) v₀ — initial upward speed (m/s) g — 9.8 m/s²

Projectile Motion

Horizontal Components
v_x = v₀cosθ  ·  x = v₀cosθ · t
Horizontal velocity is constant — no horizontal acceleration. x grows linearly with time.
v_x — horizontal velocity (m/s, constant) v₀ — launch speed (m/s) θ — launch angle above horizontal
Vertical Components
v_y = v₀sinθ − gt
Vertical motion is free fall. v_y = 0 at the peak. Use all four kinematic equations vertically.
v_y — vertical velocity (m/s) v₀sinθ — initial vertical speed (m/s) g — 9.8 m/s²
Range (level ground)
R = v₀²sin(2θ) / g
Maximum range at θ = 45°. Complementary angles (e.g. 30° and 60°) give equal range.
R — horizontal range (m) v₀ — launch speed (m/s) θ — launch angle

Key Values & Units

Constants
g = 9.8 m/s² (use 10 for quick estimates)
Free fall: a = −9.8 m/s² (up positive)
Speed of light: c = 3 × 10⁸ m/s (not needed here)
SI Units
Position / displacement: m
Velocity / speed: m/s
Acceleration: m/s²
Time: s
Scalars vs. Vectors
Vectors (have direction): displacement, velocity, acceleration
Scalars (no direction): distance, speed, time

What the AP Exam Tests

Exam focus Kinematics questions split evenly between calculation and conceptual reasoning. Expect motion graphs (position-time, velocity-time, acceleration-time) in multiple-choice and a projectile or free-fall FRQ almost every year.

Big Idea 1 — Displacement ≠ Distance

Displacement is a vector (direction matters); distance is a scalar (total path length). An object that goes 5 m right and 5 m back has zero displacement but 10 m of distance. AP questions exploit this distinction constantly.

Big Idea 2 — Acceleration ≠ Speeding Up

Acceleration means velocity is changing — that includes slowing down, changing direction, or both. An object with constant speed moving in a circle is accelerating. An object with velocity and acceleration pointing in opposite directions is decelerating.

Big Idea 3 — Kinematic Equations Require Constant Acceleration

The four kinematic equations only apply when acceleration is constant throughout the interval. For free fall and projectile motion, a = −g is constant. If acceleration varies, you need graphs or calculus (not tested in AP Physics 1).

Big Idea 4 — Projectile Axes Are Independent

Horizontal and vertical motion don't affect each other. Treat them as two separate 1D problems connected only by time. A ball dropped and a ball thrown horizontally from the same height hit the ground at the same time — horizontal speed doesn't affect vertical free fall.

Reading Motion Graphs

Position-Time (x vs. t)

  • Slope = velocity
  • Horizontal line → object at rest
  • Straight line (non-zero slope) → constant velocity
  • Curve → changing velocity (acceleration)
  • Object returns to start when x returns to its initial value

Velocity-Time (v vs. t)

  • Slope = acceleration
  • Area under curve = displacement (not distance)
  • Horizontal line → constant velocity (zero acceleration)
  • Crosses zero → object momentarily at rest, then reverses direction
  • Area above x-axis is positive displacement; below is negative

Acceleration-Time (a vs. t)

  • Horizontal line → constant acceleration (kinematic equations apply)
  • Flat line at zero → constant velocity
  • Area under curve = change in velocity (Δv)

Common Exam Traps

Trap 1 — Sign errors Always define a positive direction at the start and stick to it. If up is positive, then g = −9.8 m/s², downward velocity is negative, and downward displacement is negative. Mixing signs mid-problem is the #1 kinematics mistake.
Trap 2 — "At maximum height" doesn't mean velocity = 0 For a projectile, v_y = 0 at the peak, but v_x is still nonzero. Total velocity at the peak = v_x = v₀cosθ. Only for straight vertical throws is total velocity zero at the peak.
Trap 3 — Picking the wrong kinematic equation Each equation is missing exactly one variable. List what you know and what you need before picking an equation. Don't just grab the first one you remember.
Trap 4 — Confusing average velocity with instantaneous velocity v_avg = Δx/Δt gives the average over an interval. Instantaneous velocity is the slope of the x-t graph at a single point. On the AP exam, "what is the velocity at t = 3 s?" means instantaneous — read the v-t graph directly.
Trap 5 — Horizontal acceleration in projectile problems There is no horizontal acceleration once a projectile is in the air (ignoring air resistance). a_x = 0 always. Only gravity acts vertically.

Problem-Solving Frameworks

1D Kinematics

  1. Define positive direction — write it down. Usually up or right is positive.
  2. List variables — write v₀, v, a, Δx, t and fill in what you know. Mark the unknown.
  3. Choose the equation that contains your unknown and all your knowns (the one missing the unused variable).
  4. Solve algebraically first, then substitute numbers. Include units throughout.
  5. Check sign and reasonableness — does the direction make sense? Is the magnitude plausible?

Projectile Motion

  1. Split into components at launch: v_x = v₀cosθ, v_y₀ = v₀sinθ.
  2. Horizontal: a_x = 0, so x = v_x · t. One equation, one unknown (usually x or t).
  3. Vertical: a_y = −g. Apply kinematic equations using v_y₀ and a = −9.8 m/s².
  4. Time connects the axes — solve for t in one axis to use in the other.
  5. Final speed: combine components with v = √(v_x² + v_y²). Direction: θ = arctan(v_y/v_x).

Must-Know Scenarios

Ball Thrown Upward from Ground

v₀ upward, a = −g. At peak: v = 0, use v² = v₀² − 2gh. Total air time = 2v₀/g. Lands with the same speed it was launched (symmetric). If launched from a height, it's no longer symmetric — use Δx = v₀t + ½at² for total displacement.

Projectile Off a Cliff

Launched horizontally (v_y₀ = 0) from height h. Vertical: h = ½gt² → t = √(2h/g). Horizontal range: x = v_x · t. Final speed: combine v_x (unchanged) with v_y = gt at impact.

Two Objects Meeting

Set their position equations equal: x₁(t) = x₂(t). Solve for t. Works for chasing problems (car catching up), objects thrown toward each other, or one dropped and one thrown upward simultaneously.

Velocity-Time Graph — Finding Displacement

Displacement = area under v-t curve. For a triangle: ½ · base · height. For a trapezoid: ½(b₁ + b₂) · h. Area below the t-axis counts as negative displacement. Total distance = sum of absolute areas.

5-Point FRQ Strategy

Free-response approach Kinematics FRQs often ask you to (1) find a quantity, (2) sketch or interpret a graph, and (3) justify a conceptual claim. Each part is scored independently — a wrong answer in part (a) doesn't block credit in part (b).

What earns full marks

  • Write the general kinematic equation before substituting numbers
  • Show your list of knowns and unknowns for full method credit
  • For graph questions: label axes, mark key points (peak, zero-crossing), and show correct shape (linear vs. curved)
  • Justify claims with physics ("because acceleration is constant, the v-t graph is linear")
  • Include units on every numerical answer
  • For projectile problems: explicitly state "horizontal and vertical motions are independent"
